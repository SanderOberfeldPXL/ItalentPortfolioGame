# Interactieve Portfolio Game

Welkom bij de interactieve versie van mijn portfolio! 
In plaats van een traditioneel CV of zelfs een website, heb ik mijn portfolio verwerkt in deze **2D top-down game**.

Sta een dag in mijn schoenen en leg hetzelfde traject af als mij door de jaren! 
Probeer al de notities en boeken onderweg te vinden om zo mijn portfolio te lezen.


## Hoe te Spelen
Om de game te spelen zonder met de code te moeten knoeien, kun je de standalone executable gebruiken:
1.  Download het bestand `main.exe`.
2.  Dubbelklik op de executable om de game te starten.

## Besturing
| Toets | Actie |
| :--- | :--- |
| Pijltjestoetsen | rondlopen |
| Spatiebalk | Interactie / Dialoog verder klikken |
| Escape | Open/Sluit Pauzemenu |
| Links/Rechts (in menu) | Volume aanpassen |
| Enter (in menu) | Game afsluiten |
